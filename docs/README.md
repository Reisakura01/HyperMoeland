# docs

本目录存放项目截图与文档。

## 截图（README 引用）

- `preview.png` —— 展开卡片（媒体面板）
- `pill.png` —— 紧凑胶囊

把截图放到这里（推荐 PNG），README 会自动引用。

## 文档

- `privacy.md` —— 隐私政策（Microsoft Store 提交必填项）。
  启用 GitHub Pages（Settings → Pages → Source: `main` 分支的 `/docs` 目录）后，
  对外 URL 为：

  ```
  https://reisakura01.github.io/Islora/privacy.html
  ```

  填到 Partner Center 的「隐私政策 URL」即可。

- `store-listing.md` —— **Microsoft Store 上架资料**：商店描述（中英）、产品功能条目、
  搜索词、更新说明、附加系统要求、年龄分级问卷答案、审核备注、截图拍摄指南。
  提交时照抄即可。
